# Jazz Interview Portfolio

A portfolio of enterprise learning technology reference implementations prepared to demonstrate technical leadership across learning architecture, AI, integrations, analytics, governance, and product operations.

> **Important:** This repository uses synthetic data and generic biopharma/commercial scenarios. It is not affiliated with, sponsored by, or an internal system of Jazz Pharmaceuticals.

## Portfolio roadmap

1. `01-global-learning-capability-hub/` — Role-based capability pathways, onboarding, mastery, adoption analytics, governance, and integration monitoring.
2. `02-ai-performance-coach/` — Planned enterprise RAG performance-support assistant with grounding, citations, role-aware retrieval, evaluation, and refusal behavior.
3. `03-lms-crm-data-integration/` — Planned API/event reference architecture for HRIS, LMS, CRM, and enterprise analytics.
4. `04-assessment-intelligence/` — Planned learning-effectiveness and assessment analytics layer.
5. `05-content-governance-agent/` — Planned governed content lifecycle and AI-assisted QA workflow.
6. `06-product-operations-dashboard/` — Planned product health, roadmap, backlog, technical-debt, dependency, and platform-health dashboard.

## Current status

The first demo, **Global Learning Capability Hub**, is implemented as a working FastAPI reference application. See its local README and architecture notes for setup and demonstration guidance.
